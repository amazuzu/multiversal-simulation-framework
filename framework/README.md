# Universe framework

**Preface:** [Not a source of truth](../README.md#preface)—mission is to understand universe and life better; we have enough tools already. By a software developer (not a professional in the universe, life, physics, or mathematics), curious about life; includes dialogue with Google Gemini. Comments and criticism welcome.

Describe life and the universe with **non-contradicting** ideas: **axioms** (what may exist), **rules** (how to specify and run a world), plus optional **features**, **assumptions**, and **questions**.

Every element file starts with **Question** / **Answer**. **Equations:** [FORMULAS.md](FORMULAS.md).
