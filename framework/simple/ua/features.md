# Ознаки (просто)

**Ознаки (features)** — опційна механіка для сценарію «цей всесвіт працює всередині іншого». Бери **FS01–FS03** лише коли модель цього потребує.

| ID | Простими словами | Далі |
|----|------------------|------|
| **FS01** | Внутрішнє «ти» й зовнішнє «ти» можуть лишатися пов’язаними через заплутаність — не копія мозку через завантаження. | [FS01](../../features/simulation/FS01-session-entanglement.md) |
| **FS02** | Наш світ може крутитися на квантовому комп’ютері батьківського світу (лише історія, не доведений факт). | [FS02](../../features/simulation/FS02-quantum-computer-host.md) |
| **FS03** | Місця, куди ніхто не дивиться, лишаються невизначеними, доки хтось не спостерігає — як гра, що малює лише те, що бачиш. | [FS03](../../features/simulation/FS03-deferred-rendering.md) |
