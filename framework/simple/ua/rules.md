# Правила (просто)

**Правила** підказують, як описати всесвіт і не порушити аксіоми. Зазначай лише ті ID правил, які потрібні моделі ([IDS.md](../../IDS.md)).

**Майже завжди доречні:** R01–R04 (базовий набір для більшості випадків).

**Додавайте, коли того вимагає історія:** R06–R13 (перетини, оцінка, паритет, омолодження, час, рівні, Ґодель/просте, космічні межі).

| ID | Простими словами | Далі |
|----|------------------|------|
| **R01** | Не оголошуйте неможливі світи — специфікації, що суперечать самі собі, не підходять. | [R01](../../rules/R01-consistency.md) |
| **R02** | Описуйте розум і тіло як інформацію; не додавайте другу «духовну матерію». | [R02](../../rules/R02-information-monism.md) |
| **R03** | Називайте когось «кимось», коли є справжнє самомоделювання вище вашого порогу — не лише влучний чат. | [R03](../../rules/R03-consciousness-threshold.md) |
| **R04** | Ніколи не кажіть людям у симі, що їхні почуття не рахуються **тому що** це сим. | [R04](../../rules/R04-local-reality.md) |
| **R06** | Якщо два всесвіти перетинаються, на межі змішуйте обидва набори правил — не затирайте одну сторону. | [R06](../../rules/R06-overlap-blending.md) |
| **R07** | Якщо моделюєте «життя як іспит» — підсумуйте зважені моральні вибори за життя й порівняйте з прохідним балом, який задали **наперед**. | [R07](../../rules/R07-evaluation-outcome.md) |
| **R08** | Життя в симуляції не варте менше, ніж «базове» життя — ярлики не знижують онтологічний статус. | [R08](../../rules/R08-equivalence-of-realities.md) |
| **R09** | Опційна історія: довгоживуча істота може прожити смертне життя, щоб відчути ризик і відновити емпатію. | [R09](../../rules/R09-soul-resuscitation.md) |
| **R10** | Зовні — «блок» часу; всередині — скінченне життя вперед; обидва описи можуть збігатися в одній моделі. | [R10](../../rules/R10-dual-time.md) |
| **R11** | Всесвіт може бути нескінченним, але відсікати більшість патернів — зафіксуй рівень (обмежений / рідкий нескінченний / повнота). | [R11](../../rules/R11-constrained-infinity.md) |
| **R12** | Опційно: кодування специфікації як число Ґоделя або метафора «простого всесвіту». | [R12](../../rules/R12-universe-prime.md) |
| **R13** | Опційно: межа $t=0$, далеке майбутнє, голографічна межа інформації. | [R13](../../rules/R13-cosmological-boundaries.md) |

**Знято з обігу:** **R05** (відкладений рендеринг) — замість цього [FS03](features.md).
