# Measures (`M**`)

**Measures** are norms or parity checks you apply when comparing worlds or scoring lore—not operational build rules like **R01**–**R07**.

| ID | File | Sources |
|----|------|---------|
| M01 | [M01-ontological-parity.md](M01-ontological-parity.md) | R08, A04 |

## How to use

- List under `references.measures` in [universe.schema.yaml](../universe.schema.yaml).
- Use when you need an explicit “no second-class **universes**” check in models or narratives (distinct from **A04**, which is “no second-class **experience**” inside one world).

**M** = measure. Files use **M01**, …
