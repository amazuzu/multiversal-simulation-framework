# R13 — The edges of the map

**Question:** If the universe is math, what is the Big Bang?

**Answer:** Maybe not an explosion **before** time. Maybe the **edge** of the coordinates—like the north pole: you can walk there, but there is no “north of north.” A far future can be another edge, where change quiets down. A size limit (“only so many bits fit”) is a third optional edge, for stories about a finite cosmos.

None of this is a lab result. Use it when your tale needs a beginning, an ending, or a ceiling. Lifespan along a path through that map: [R10](R10-dual-time.md).

## Advanced

$$\lim_{t \to \infty} \frac{dS}{dt} = 0$$

**Read it as:** as time runs to the far edge, the *rate* of entropy change flattens to zero. $dS/dt$ is “how fast disorder is still growing.” The beginning $t = 0$ is a boundary of the coordinates, like a pole on a globe, not a moment that has a “before” inside the same clock.

A size ceiling sometimes quoted in holographic talk is about $10^{122}$ bits for the visible cosmos. Order-of-magnitude folklore, not a measurement we made.
