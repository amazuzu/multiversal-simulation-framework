# AS02 — Session amnesia / unbiased testing (optional)

## Q&A

**Question:** Why don’t we remember past lives—or a “higher” world—during this life?

**Answer:** **Only if you turn AS02 on:** memories that would bias the session (past lives, base layer, test status) stay withheld until the run ends. An optional **story** for why is blind vetting ([Q01](../questions/Q01-existential-purpose.md)). We do not know if this is true for Earth.

**Status:** *Guess only.* Memory protocol + optional hiring narrative as one toggle. Former **L02**. See [IDS.md § ID migration](../IDS.md#id-migration-retired-numbers).

## When AS02 applies

| Case | AS02 | Reading |
|------|------|---------|
| Single life, no session test | off | Not a claim about our memories. |
| Repeated sessions / blind sampling | on | Active memory excludes withheld “primary” partition for this life. |
| Sim + blind vetting | on | Hiring story explains *why*; partition explains *how*. |

Withheld (not destroyed) during the session:

| Partition | Typical contents |
|-----------|------------------|
| Origin | Base layer, pre-embodiment identity |
| Prior lives | Recall of earlier sessions |
| Meta | Test/sim status, immortality, outcomes, briefings |

**Equations:** [FORMULAS.md § AS02](../FORMULAS.md#as02--active-memory-without-primary-knowledge)

## Why forgetting (when on)

1. Unbiased choices per life (veil-of-ignorance style across lives).
2. Behavior must not depend on what primary memory would reveal.
3. Post-death evaluation ([Q01](../questions/Q01-existential-purpose.md)) can integrate lives **after** each session.

## Hiring guess (plain language)

If life is a sim from a higher layer, one purpose is **validation**: live without insider knowledge; after death, something judges fit for serious responsibility. Amnesia keeps the test honest.

## If you adopt AS02

List under `references.assumptions`; configure `session.memory` ([universe.schema.yaml](../universe.schema.yaml), [earth-session.yaml](../examples/earth-session.yaml)).

**Checks:** primary memory does not steer mid-session actions; leaks break blind test unless allowed; outcomes after death belong to Q01, not in-session recall.

## If you do not adopt AS02

No required amnesia; omit from `references.assumptions`.
