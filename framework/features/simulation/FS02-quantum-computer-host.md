# FS02 — Quantum computer host (N qubits)

## Q&A

**Question:** Could our universe run on a quantum computer with **N** qubits in a parent world?

**Answer:** A **possible hosting story**, not a fact. The outer layer might be a device whose state space scales like 2^N (idealized), perhaps with [FS03](FS03-deferred-rendering.md) so not every detail is stored at once.

**Status:** *Simulation feature.* Speculative. We do not claim Earth is on such hardware.

## What this means

- **Host:** parent universe contains a quantum simulator with **N** qubits (you choose N).
- **Guest:** inner universe is dynamics implemented on that hardware.
- Larger N ⇒ more room for inner state; noise, algorithms, and partial rendering still matter.

**Equations:** [FORMULAS.md § FS02](../../FORMULAS.md#fs02--quantum-host-optional) (sketch)

## If you enable FS02

**Checks:** state parent has quantum host with N; inner sim exact or effective; if FS01 is on, say how observers couple to guest state.

## If you do not enable FS02

Nested sim may use classical substrate or unknown implementation ([A02](../../axioms/A02-mathematical-monism.md)).
