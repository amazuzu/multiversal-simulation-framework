# FS02 — A computer in the sky (maybe)

**Question:** Could our universe run on a quantum computer somewhere “above”?

**Answer:** It’s a **hosting story**, not a discovery. A parent world might run a machine with N qubits; more qubits, more room. You can pair it with “only draw what someone sees” ([FS03](FS03-deferred-rendering.md)).

Asking “who built the computer’s universe?” never ends. These notes don’t need a bottom machine—only rules that fit ([A01](../../axioms/A01-non-contradiction.md)). Rough folklore once said a few hundred to a thousand logical qubits might “hold a cosmos.” Treat that as a campfire number, not a measurement.

## Advanced

$$\text{number of basic states} = 2^{N}$$

**Read it as:** $N$ ideal qubits can label $2^N$ combinations (1 qubit → 2, 10 qubits → 1024). The inner universe would be some dynamics *inside* that space. Bigger $N$, more room. Noise and “don’t render everything” ([FS03](FS03-deferred-rendering.md)) still matter.
