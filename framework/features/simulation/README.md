# Simulation features (`FS**`)

Use when **this universe is a simulation inside another** (nested / hosted). These describe how the inner world can couple to the outer one—not whether simulation is true (that may be [Q01](../../questions/Q01-existential-purpose.md), [AS02](../../assumptions/AS02-session-amnesia.md), etc.).

| FS03 | [FS03-deferred-rendering.md](FS03-deferred-rendering.md) | Observer-linked / lazy world detail (former **L04**, **U01**) |

## YAML

```yaml
references:
  features:
    simulation: [FS01, FS03]  # minimal: only IDs matching enabled session/physics flags; + FS02 if host narrative
```
